# Israel Asefa — Software Engineering Portfolio

Personal portfolio for Israel Asefa, a backend-heavy software engineer based in Addis Ababa, Ethiopia.

The site presents selected work across backend systems, payments, infrastructure tooling, production debugging, and full-stack product delivery. It is designed to make the architecture and engineering decisions behind each project easier to understand, rather than acting as a simple gallery of screenshots.

## Featured work

- **Threadline** — runtime evidence collection and flow reconstruction for backend debugging
- **Odoo Infrastructure Control Plane** — remote provisioning and lifecycle management for Odoo deployments
- **Payment and ledger systems** — backend-controlled credit, checkout, webhook, subscription, wallet, and ownership workflows
- **Business workflow systems** — operational tooling, integrations, and production support for real business processes

## Technical focus

- Java and Spring Boot
- Python and FastAPI
- Node.js and TypeScript
- PostgreSQL and relational data modelling
- REST APIs, payments, integrations, and asynchronous workflows
- Docker, infrastructure tooling, and production debugging

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
